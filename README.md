# PokeMem · 宝可梦151抽卡 v1.1（网页版）

> v1.1（2026-11-16）：修了“点开一包没反应”的 bug。原因是浏览器里顶层 `const POKEDEX` 不会挂到 `window` 上，`gacha.js` 读 `window.POKEDEX` 拿到空数组，抽卡直接抛错、按钮静默无反应。已改成 `pokedex.js` 显式挂 `window.POKEDEX`，并用浏览器环境复现验证过开包成功；另加了页面顶部报错红条，以后出错不会再一声不吭。

> v1.2（2026-11-16）：修了开包卡片“图片和框对不上”（等级/HP/攻击那行被卡框下沿切掉一半）。原因是卡片写死了 190px 高、内容用绝对定位撑满，内容一多就溢出。已改成卡片高度由内容决定（正反两面叠在同一格里翻牌），图片限高 96px，卡面背面保底 232px 高。

> v1.3（2026-11-16）：顶部加了中文 / EN 切换，随时可换。切英文后界面文案、宝可梦名、属性、稀有度、等级数值单位（攻击→ATK）都变英文；搜名字时中英文都能搜；语言选择存在存档里，刷新不丢，清空存档也不重置语言。

> v1.4（2026-11-16）：稀有度标记画在稀有度文字边上：N 黑点 1 个、R 黑星 1 颗、SR 黑星 2 颗、SSR 金星 1 颗、UR 金星 2 颗、MR 粉星 1 颗（开包卡、卡册、详情、概率表四处都有）。SSR / MR 翻牌时有炉石式震动：左右晃 + 微放大 + 稀有度颜色光晕，逐张点和全部翻开都会触发。

> v1.5（2026-11-16）：卡册点开某只宝可梦，详情页会列出它的全部卡（每张的 Lv / HP / 攻击），点 Lv / HP / 攻击按钮排序，再点同一个按钮切换升序降序。之前抽的卡只有汇总，启动时自动迁移：最高数值那张补一条明细，剩下的记为旧卡并在详情页注明张数。

> v1.6（2026-11-16）：修了开包结果里「返回抽卡」按钮看不见字的问题。原因是 `.overlay-actions button` 的白底（优先级更高）盖住了 `.big-btn` 的红底，字还是白的，白字白底。已在 style.css 里把红底白字写回来；按钮文案也从“收入卡册”改成“返回抽卡”（英文 Back to Packs）。


宝可梦 151 只抽卡小游戏的网页版框架。纯静态页面（HTML/CSS/JS，无后端），手机和电脑浏览器都能打开；后续可套壳成 App 或部署到 Cloudflare。

## 怎么玩（测试）

1. 直接双击打开 `index.html`，或在目录里跑 `python -m http.server 8000` 后访问 `http://localhost:8000`。
2. 首次进入自带 1 包卡包。点「开一包」抽 10 张，点卡牌逐张翻开。
3. 「卡册」随时查看 151 只的收集情况（支持按稀有度 / 已拥有 / 未拥有筛选、搜名字或编号）；点任意一只看详情（属性、概率、拥有数、最高等级的 HP/攻击）。
4. 「概率」页能看到每档的档位合计与单只概率。

存档存在浏览器 localStorage 里（`pokemem-save-v1`），同一浏览器刷新不丢失；换浏览器/设备是另一份存档。

## 规则（v1 已实现）

- **卡包**：正式版每小时自动获得 1 包，每包 10 张。离开页面再回来会按流逝时间补发（每小时 1 包）。
- **概率**：按图鉴表 L 列单只概率加权抽取 —— N 1.04%、R 1.43%、SR 0.24%、SSR 0.27%、UR 0.25%、MR 0.13%。
  表格 151 只合计 99.89%（四舍五入所致），代码按权重归一化到 100%。
  档位合计：N 49.92% / R 30.03% / SR 14.88% / SSR 4.05% / UR 0.75% / MR 0.26%。
- **保底**（另一位工程师的文档第 6–7 节）：每包至少 1 张 SR 及以上；连续 50 抽未出 SSR 则下一抽必出 SSR 及以上；MR 不设保底。
  实现细节：10 连保底做成“前 9 张正常抽，第 10 张若仍无 SR+ 则强制从 SR+ 池抽”，展示时打乱顺序，与文档“抽完随机替换一张”的保底概率完全一致。
- **等级与数值**（文档第 4 节 / 图鉴表“等级公式”页）：等级在最低等级～100 间随机；
  HP = ⌊(2×HP种族值+93)×等级÷100⌋+等级+10；攻击 = ⌊(2×攻击种族值+93)×等级÷100⌋+5。
  例：妙蛙种子 50 级 → HP 151、攻击 100。
- **重复卡**：卡册里记拥有数量和最高等级那张的数值；开包时首次获得的卡标 NEW。

## Debug 模式 vs 正式版

- 页面底部有个「Debug 模式」开关。打开后出现 Debug 面板：随意加包（输入数字或 +1/+10/+100）、下一包立即到账、清空存档；计时暂停。
- 关掉开关即回正式版：每小时 1 包，计时继续走。**Debug 加的包切回正式版后仍保留**（只影响获得速度，不回收已发的包）。
- 想完全按正式版测试：保持开关关闭，等 1 小时拿 1 包；或先 Debug 加包测完，点「清空存档」后再关掉开关重新开始。
